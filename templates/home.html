Flujo de datos

Dónde viven los datos

La carpeta db/ contiene la base SQLite con los registros reales de incautaciones. El archivo path.py sigue siendo útil para documentar el origen del dataset desde Kaggle y futuras cargas.

Flujo de frontend

Dónde viven las implementaciones del mapa

Cada plantilla puede cargar un script dedicado desde static/. Eso mantiene aislado el código específico de cada librería y facilita comparar Leaflet, OpenLayers y MapLibre lado a lado.
